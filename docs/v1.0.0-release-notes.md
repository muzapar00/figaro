# 费加罗 v1.0.0 · Figaro v1.0.0

**第一个正式版：Linux 可用、三语界面、通用 LLM、按地区选择的模型下载、本地长期记忆，以及完整的隐私说明。**

这是一个"可交付给别人用"的版本：不再需要从仓库手改配置才能跑起来，安装、引导、服务商配置、
模型下载都有明确路径；所有数据仍只在你自己的机器上（见 [privacy.md](privacy.md)）。

## 亮点

### 🧭 三语界面 + 新手引导
- 设置窗口支持 **简体中文 / 繁體中文 / English**，默认跟随系统语言，可在设置里切换（无需重启）。
- 全新的新手引导：用大字、通俗的话说明「费加罗是什么、接下来要做什么」；
  隐私声明、语言、地区、API key、麦克风/F9/声纹自检、长期记忆开关，一步一步完成。
- 服务商引导卡片：DeepSeek / OpenAI / Gemini（LLM）与 MiniMax（音色），
  带"推荐服务商"小字和 ⓘ 说明：我们不提供实时 LLM/TTS 服务，需要你自己的 API key；
  key 只存本机，可随时更换或使用本地 OpenAI 兼容端点（Ollama/vLLM 等）。

### 🔌 通用 LLM API
- 支持 **DeepSeek / OpenAI / Gemini / 自定义 OpenAI 兼容端点**；旧 `deepseek.*` 配置自动兼容。
- 可在设置里切换 provider、baseUrl、model、key，并测试连接。
- 工具调用、流式输出、重试/超时对 OpenAI 兼容与 Gemini 原生协议都可用。

### 🌏 按地区选择模型下载源
- 中国大陆：自动走国内镜像（ModelScope / hf-mirror / ghproxy，按可用性回退）；
- 中国港澳台 / 海外及其他：官方直连或本地镜像，可手动覆盖。
- 首次引导里选择地区；命令行也支持 `scripts/fetch-models.sh --region mainland|hmt|overseas`。

### 📦 Linux 打包与兼容性
- 新增 **deb**（Ubuntu 26.04 / Kubuntu / KDE neon）、**AUR**（Arch）、**rpm**（Fedora/openSUSE）打包；
  GitHub Actions 在 tag 时自动构建并上传 Release assets。
- 兼容矩阵与回退说明见 [platform-support.md](platform-support.md)：
  KDE Plasma 6 Wayland 正式支持；Hyprland/sway 提供测试步骤与回退；
  GNOME Wayland 因缺少 wlr-layer-shell 暂不支持浮层；X11 不支持；Flatpak/AppImage 不推荐。
- 非 KDE 环境：截图走 xdg-desktop-portal，液态玻璃自动回退为半透明。

### 🧠 本地长期记忆（RAG）
- 使用成熟的 **LightRAG（MIT）** 作为本地检索服务，MiniMax `embo-01` 做 embedding，
  DeepSeek 做抽取/查询；不依赖云端向量库。
- 每轮回答前按预算召回、回答后可后台入库；服务不可用时静默降级，不影响语音。
- **隐私默认**：自动入库默认关闭；开启前会明确告知"对话文本会发送给你配置的 LLM/Embedding 服务商"。
  可随时清空 `~/.local/share/figaro/lightrag/data/`。

### 🎙️ 语音体验（自 0.1.0 起累积）
- 中英双语唤醒词 + 声纹门（只认你的声音），F9 长按；
- 说完话静音 3 秒才提交，不再把人声掐断；唤醒后 7 秒没说话安静退下；
- 说话打断、取消词/退下词、唤醒应答短语随机化；
- 屏幕查看、文件/命令/网页工具、Home Assistant 控灯（米家设备）。

## 隐私与自由
- 无遥测、无账号、无我们提供的服务器；唤醒/ASR/声纹/工具全部本机完成；
- API key 仅存本机（600），设置界面只显示掩码；
- GPL-3.0-or-later，可读、可改、可再分发；完整说明见 [privacy.md](privacy.md)。

## 升级（从 0.1.0）
1. 拉取新代码（或安装新包）后运行 `figaro install-user`（源码安装用户重跑 `./install.sh`）；
2. `figaro doctor` 检查依赖；`scripts/fetch-models.sh --region ...` 可补齐模型；
3. 旧配置自动兼容；想用长期记忆再启动 `figaro-rag`（见 [rag.md](rag.md)）。

## 已知限制
- Windows / macOS 暂不支持（需要重写 UI/音频/热键平台层，见 docs/platform-support.md）；
- GNOME Wayland 无 layer-shell，浮层需要额外扩展；X11 不支持；
- 模型文件不随安装包分发，首次使用需按地区下载（约 200–300 MB）；
- 长期记忆的抽取需要调用 LLM/Embedding 服务商（可用本地 OpenAI 兼容端点替代）。
